Architectural Overview

Understanding the theoretical differences behind each evaluation candidate.

1. HOG + Linear SVM

Classical Computer Vision Pipeline

  • Feature Extraction: Histogram of Oriented Gradients captures edge structures and local shape distributions.
  • Classifier: Convex Linear Support Vector Machine maximizing class decision hyperplanes.
  • Strengths: Extremely fast CPU execution, lightweight memory footprint, zero parameter overhead.
  • Limitations: Sensitive to object rotations, illumination changes, and complex background clutter.

2. Custom CNN

Scratch Deep Convolutional Neural Network

  • Architecture: 4 convolutional blocks incorporating batch normalization, ReLU activations, and max-pooling.
  • Optimization: End-to-end learning trained directly on 45,000 CIFAR-10 training images.
  • Strengths: Automatically learns hierarchical visual features without manual engineering.
  • Limitations: Prone to overfitting without heavy regularization; requires GPU training time.

3. Fine-Tuned ResNet-18

Pretrained Residual Network

  • Architecture: 18-layer residual network utilizing skip connections to eliminate vanishing gradients.
  • Transfer Learning: Pretrained on ImageNet and fine-tuned specifically for CIFAR-10 resolution.
  • Strengths: Highest spatial representation power, robustness, and superior accuracy.
  • Limitations: Higher computational cost per prediction and millions of parameters.
