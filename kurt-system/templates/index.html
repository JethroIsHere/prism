Architectural Overview

Core design choices, parameter footprints, and empirical trade-offs documented in the CCS 250 study.

1. HOG + Linear SVM

Classical Computer Vision Pipeline (Slot A)

  • Feature Extraction: Converts 32×32 RGB inputs to grayscale and extracts a 1,764-D Histogram of Oriented Gradients descriptor using 4×4 pixel cells and L2-Hys block normalization.
  • Classifier: One-vs-Rest Linear SVM trained via hinge-loss mini-batch SGD in NumPy (17,650 learned decision weights; 0.00M neural parameters).
  • Strengths: Ultra-fast 0.13 ms/image CPU inference and 0.8-minute training time; handles rigid vehicles reliably (Automobile & Truck F1 = 0.66).
  • Limitations: Fixed edge descriptors struggle with deformable poses and background clutter, dropping to 52.06% overall accuracy (Cat F1 = 0.30).

2. Custom 4-Block CNN

Scratch Deep Learning Architecture (Slot B)

  • Architecture: Four sequential Conv-BatchNorm-ReLU blocks expanding channels (32→64→128→256) with Max Pooling and Global Average Pooling (391,466 trainable parameters).
  • Optimization: Trained from random weights for 30 epochs on 45,000 CIFAR-10 images using Adam, Cosine Annealing, and random crop/flip augmentation.
  • Strengths: Automatically learns hierarchical visual features, jumping to 85.22% Top-1 accuracy (0.8519 Macro F1) at 0.29 ms/image GPU latency.
  • Limitations: Lacks large-scale pretraining priors, leaving residual errors between visually similar animals such as cats (F1 = 0.71) and dogs (F1 = 0.78).

3. Fine-Tuned ResNet-18

Transfer Learning Baseline (Slot C)

  • Architecture: 18-layer deep residual network with identity skip connections, replacing the 1,000-class head with a 10-class CIFAR-10 classifier (11.18M parameters).
  • Transfer Learning: Initialized with ImageNet weights, bilinearly upsampling 32×32 inputs to 224×224 and fine-tuning all layers across 12 epochs.
  • Strengths: Delivers 96.30% Top-1 accuracy and 0.9630 Macro F1, resolving fine-grained animal textures (Cat F1 = 0.9219; Dog F1 = 0.9333).
  • Limitations: Requires the largest memory footprint (11.18M parameters), 30.4-minute GPU training time, and 2.22 ms/image inference latency.

4. Color Histogram + k-NN

Classical Non-Parametric Baseline (Slot D)

  • Feature Extraction: Computes a 24-dimensional normalized RGB color histogram (8 bins per channel) on 32×32 images without spatial edge descriptors.
  • Classifier: Lazy k-Nearest Neighbors (k = 20) using Chi-Squared histogram distance across all 45,000 training samples (0.00M trainable weights).
  • Strengths: Instant 0.18-minute indexing and handles color-distinct scenes like airplanes (F1 = 0.46) and frogs (F1 = 0.41) above random chance.
  • Limitations: Lacks shape and spatial awareness, yielding 33.40% Top-1 accuracy and 14.20 ms/image CPU search latency.

5. Fine-Tuned EfficientNet-B0

Compound-Scaled Transfer Network (Slot E)

  • Architecture: Mobile inverted bottleneck (MBConv) blocks with Squeeze-and-Excitation channel attention and compound scaling (4.02M parameters).
  • Transfer Learning: Initialized with ImageNet weights and fine-tuned across 12 epochs using Adam, Cosine Annealing, and ImageNet normalization.
  • Strengths: Achieves 79.88% Top-1 accuracy (0.7982 Macro F1) with 64% fewer parameters than ResNet-18 (4.02M vs. 11.18M).
  • Limitations: Evaluated on 32×32 inputs rather than native 224×224 resolution, capping fine-grained animal separation compared to ResNet-18.
